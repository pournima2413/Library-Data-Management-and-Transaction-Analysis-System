# Library-Data-Management-and-Transaction-Analysis-System
## Project Description

This project focuses on building a relational database system to manage library records and analyze transaction activity using SQL. The system organizes data related to books, members, and borrowing history, and supports queries that help understand usage patterns, overdue behavior, and overall system activity.

The project emphasizes structured database design, data integrity through constraints, and analytical querying to extract meaningful information from transactional data.
---
## Purpose of the Project
Objectives

-Design and initialize a relational database to manage library-related data, including branches, staff, members, books, and transaction records.

-Populate the database with structured data to support operational and analytical queries.

-Perform standard data operations such as inserting new records, retrieving existing data, modifying records, and removing obsolete entries.

-Apply Create Table As Select (CTAS) techniques to generate derived tables based on query results.

-Develop and execute advanced SQL queries to extract specific information and analyze patterns within the data.
